# Ariadne Python Common

Low-level infrastructure shared by the Python bindings of the Ariadne component repositories. Although independently maintained and usable, this repository is also part of the [Ariadne repository structure](https://github.com/ariadne-cps/ariadne/blob/main/doc/structure.md).

The repository intentionally contains only binding infrastructure that is independent of Ariadne modules. Module-specific helpers belong to the repository that owns the corresponding C++ types.
